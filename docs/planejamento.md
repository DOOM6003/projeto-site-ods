# Cronograma de desenvolvimento

## Sprint 2 — Planejamento e prototipação

* Definir as páginas e funcionalidades do site.
* Pesquisar informações em fontes confiáveis.
* Elaborar os wireframes das principais telas.
* Organizar a estrutura inicial do repositório no GitHub.

**Entregas:** planejamento das páginas, referências iniciais e protótipo visual.

## Sprint 3 — Desenvolvimento e validação

* Desenvolver a estrutura das páginas com HTML.
* Aplicar o estilo visual com CSS.
* Implementar funcionalidades com JavaScript, se necessário.
* Testar a navegação, a acessibilidade e a apresentação das informações.
* Corrigir problemas identificados.

**Entregas:** primeira versão funcional do site e registro das alterações no GitHub.
