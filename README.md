# Voz Delas

## Sobre o projeto

O **Voz Delas** é um projeto acadêmico desenvolvido na disciplina de Desenvolvimento Web, com foco na conscientização e no enfrentamento da discriminação de gênero.

A proposta é criar um site que incentive mulheres que sofrem algum tipo de desigualdade (especialmente no ambiente de trabalho) a fazer denúncias em um ambiente anônimo, o que traz mais segurança para elas. O projeto também busca informar sobre direitos, conscientizar sobre situações de discriminação de gênero e dar visibilidade a relatos de desigualdade, facilitando a consulta e o acompanhamento dos registros.

O projeto está alinhado ao **Objetivo de Desenvolvimento Sustentável 5 (Igualdade de Gênero)** da ONU.

## Funcionalidades previstas

- **Conteúdos educativos:** informações sobre igualdade de gênero, direitos e discriminação.
- **Registro de relatos e denúncias:** espaço para denunciar situações de discriminação de gênero.
- **Anonimato nas denúncias:** as informações ficam visíveis apenas para os administradores.
- **Acompanhamento:** identificação de denúncias atendidas e não atendidas.

## Identidade visual

A identidade visual é inspirada no **Outubro Rosa** e combina o branco com diferentes tons de rosa. A ideia é transmitir acolhimento, força e clareza, com uma interface simples e fácil de navegar.

### Paleta de cores

As cores estão configuradas como classes personalizadas do Tailwind CSS.

#### Rosas (cores principais)

| Nome (classe Tailwind) | Código    | Uso                                          |
|------------------------|-----------|----------------------------------------------|
| `rosa-mais-escuro`     | `#880E4F` | Rosa mais escuro, também é a base das sombras |
| `rosa-escuro`          | `#C2185B` | Cor de destaque principal                    |
| `rosa-medio`           | `#E91E63` | Rosa vivo                                    |
| `rosa-claro`           | `#F8BBD0` | Brilhos em degradê no fundo                  |
| `rosa-bem-claro`       | `#FCE4EC` | Cor de fundo da página                       |

#### Texto e neutros

| Nome          | Código    | Uso                                  |
|---------------|-----------|--------------------------------------|
| `texto`       | `#3A2430` | Texto principal                      |
| `texto-suave` | `#6D5560` | Texto secundário                     |
| `placeholder` | `#B39AA6` | Texto de exemplo dentro dos campos   |
| `borda`       | `#F0C6D6` | Bordas e divisórias                  |
| `white`       | `#FFFFFF` | Cartões e caixas                     |

#### Mensagens de status

| Nome      | Código    |
|-----------|-----------|
| `erro`    | `#B00020` |
| `sucesso` | `#2E7D32` |

#### Sombras

As sombras usam o `#880E4F` com transparência:

| Nome            | Valor                                   |
|-----------------|-----------------------------------------|
| `shadow-topo`   | `0 2px 10px rgba(136, 14, 79, 0.08)`    |
| `shadow-cartao` | `0 18px 40px rgba(136, 14, 79, 0.15)`   |
